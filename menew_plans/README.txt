MENEW - STUDENT 2 (Plan Details + Add New Plan)

FILES
- plan-details.html: subscription plan cards
- add-plan.html: create a new subscription plan
- plans.css: responsive styles, CSS variables, Grid and Flexbox
- plans.js: demo plans, form logic, localStorage persistence

HOW TO TEST
1. Open plan-details.html in your browser (or use VS Code Live Server).
2. Click Add New Plan.
3. Fill in all required fields, then click Save Plan.
4. Your new plan should appear on the Plan Details page.
5. Try invalid fields and test on a narrow/mobile viewport.

HOW TO MERGE INTO A TEAM GITHUB REPOSITORY
1. Add all four files to the repository, ideally in the same directory.
2. Student 1's home page should be named index.html, or change the Home links in both HTML files.
3. Add links to plan-details.html and add-plan.html in the team's shared navigation.
4. If the team already has shared CSS/navigation, coordinate styles and replace the example nav in both pages.
5. Run the site using the team's chosen local server.

IMPORTANT
- This demo uses browser localStorage, NOT a shared backend/database. Plans are saved on the same browser/device only.
- The sample prices are fictional example data; adjust to team requirements.
